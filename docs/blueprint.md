# **App Name**: Nib Memo

## Core Features:

- Memo Creation: Enable users to create memos with fields for Date (auto-generated), From, To, Subject, CC, and Body content, and attachments.
- Recipient Selection: Allow users to directly select recipients based on the bank's organizational structure (Division, Department, Office).
- Memo Delivery: Digitally send memos directly to selected recipients within the system.
- Activity Tracking: Track all actions taken on each memo, including timestamps, sender, recipient, and actions, displayed in a chronological history.
- Acknowledgement and Feedback: Implement features allowing users to acknowledge receipt and provide feedback or comments on memos.
- Delegation Function: Allow recipients to delegate a memo to other users, while maintaining the original memo's activity history.

## Style Guidelines:

- Primary color: Deep blue (#935724) to evoke trust and professionalism.
- Background color: Light gray (#F2F4F4), a desaturated version of the primary, for a clean, uncluttered look.
- Accent color: Soft gold (#f6bb14), analogous to deep blue, used sparingly to draw attention to key actions and interactive elements.
- Body and headline font: 'Inter' for a modern, neutral, objective feel. Use throughout for readability and consistency.
- Use simple, consistent and colorful icons to represent memo status (sent, received, acknowledged) and actions (delegate, reply, archive).
- Prioritize a clean, tabular layout for memos and activity logs, ensuring clarity and ease of navigation.
- Use subtle transitions and animations to indicate status changes and provide feedback on user actions (e.g., memo submission, acknowledgement).
